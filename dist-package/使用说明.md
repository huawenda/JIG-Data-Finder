# JIG Data Finder 2.0 — 使用说明

MES JIG 数据查询助手。

---

## 一、安装

### 需要什么

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 1803 及以上 / Windows 11（64 位） |
| 其他依赖 | **无**。不需要装 .NET、Python、Java 或任何运行库 |
| 磁盘空间 | 约 20 MB |

Windows 10 / 11 自带 WebView2 运行时，本程序直接使用。

### 怎么装

1. 把 `jig-data-finder.exe` 复制到任意目录（建议放在 `D:\JIGDataFinder\`）
2. 双击运行

**就这样。没有安装向导，不需要注册表，不需要卸载程序。**

> 程序不会往源 Excel 文件写任何东西，只读取。

---

## 二、怎么用

### 第一步：加载源数据

点顶部「浏览…」选择 MES 导出的 Excel 文件，再点「加载」。

- 支持 `.xlsx` 和 `.xls`
- 必须包含 `Jig ID` 列，否则会提示「源文件中未找到 Jig ID 列」
- 加载成功后底部状态栏显示行数

### 第二步：查询

1. 在左侧「输入 JIG ID」框里粘贴 JIG 编号，**每行一个**
2. 点「开始查询」（或按 `Ctrl + Enter`）

**可以直接粘贴邮件正文**，程序会自动挑出里面的 Jig ID 并忽略其余文字。例如粘贴：

```
各位好，
附件里的 JIG 如下，麻烦查一下：
CJJ349000910 和 CJJ349000919
谢谢
```

左侧会变成：

```
CJJ349000910
CJJ349000919
```

### 第三步：看结果

四个标签页：

| 标签页 | 内容 |
|---|---|
| 🔍 查询结果 | 本次查询的明细，每行一个 JIG |
| 📊 结果透视 | 本次查询按 P/N 和工序汇总 |
| 📈 全量透视 | 全部数据汇总，可切「全部数据 / 生产中」 |
| 📋 数据审查 | 全部明细，可按 P/N 下拉筛选 |

**尺寸验证**：在「查询结果」页勾选「标出尺寸不匹配」，对应尺寸会用红色标出——这些 JIG 的编号与尺寸对不上，需要现场确认。导出 Excel 时红色标记也会保留。

**工序轨道**（透视页顶部）：把产线的十道工序按顺序排开，每道工序显示当前有多少个 JIG 停在那里，置灰表示没有。产线卡在哪一步一目了然。

### 导出

点右下角「导出…」，选择保存位置。文件名会自动带时间戳（可在设置里关闭），不会覆盖旧文件。

## 三、常见问题

**Q：双击没反应 / 闪退**
系统缺 WebView2 运行时。到微软官网下载「Evergreen Standalone Installer」安装后重试：
https://developer.microsoft.com/microsoft-edge/webview2/

**Q：提示「源文件中未找到 Jig ID 列」**
源文件表头里没有 `Jig ID` 这一列。请确认选对了 MES 导出的文件。

**Q：粘贴后没反应**
「设置 → 数据处理 → 粘贴时提取 JIG ID」需处于开启状态。另外含空格或特殊字符的内容不会被识别为 Jig ID。

**Q：尺寸验证把整列都标红了**
`对应尺寸` 列依赖「Jig 对应型号」列的映射。型号不在映射表内时尺寸为空，空值默认视为匹配，不会标红。如果型号明明存在却没尺寸，请联系反馈。

**Q：窗口关掉了，人还在吗？**
默认「关闭时最小化到系统托盘」。双击托盘图标恢复，右键托盘图标 →「退出程序」才真正退出。可在设置里改。

**Q：配置存在哪？**
`%APPDATA%\JIG Data Finder\config.json`。升级新版时会沿用旧版（1.x）的配置，不用重新设置。

**Q：数据量大会不会卡？**
10 万行实测流畅（表格只渲染可视区的行）。加载 10 万行约 3 秒。

**Q：如何卸载**
删掉 `jig-data-finder.exe` 即可。配置在 `%APPDATA%`，如需彻底清除一并删除该目录。
