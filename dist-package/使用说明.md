# JIG Data Finder 2.0 — 使用说明

MES JIG 数据查询助手。

---

## 一、安装

### 需要什么

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 1803 及以上 / Windows 11（64 位） |
| 其他依赖 | **无**。不需要装 .NET、Python、Java 或任何运行库 |
| 磁盘空间 | 约 20 MB |

Windows 10 / 11 自带 WebView2 运行时，本程序直接使用。

### 怎么装

1. 把 `jig-data-finder.exe` 复制到任意目录（建议放在 `D:\JIGDataFinder\`）
2. 双击运行

**就这样。没有安装向导，不需要注册表，不需要卸载程序。**

> 程序不会往源 Excel 文件写任何东西，只读取。

---

## 二、怎么用

### 第一步：加载源数据

点顶部「浏览…」选择 MES 导出的 Excel 文件，再点「加载」。

- 支持 `.xlsx` 和 `.xls`
- 必须包含 `Jig ID` 列，否则会提示「源文件中未找到 Jig ID 列」
- 加载成功后底部状态栏显示行数

### 第二步：查询

1. 在左侧「输入 JIG ID」框里粘贴 JIG 编号，**每行一个**
2. 点「开始查询」（或按 `Ctrl + Enter`）

**可以直接粘贴邮件正文**，程序会自动挑出里面的 JIG ID 并忽略其余文字。例如粘贴：

```
各位好，
附件里的 JIG 如下，麻烦查一下：
CJJ349000910 和 CJJ349000919
谢谢
```

左侧会变成：

```
CJJ349000910
CJJ349000919
```

### 第三步：看结果

四个标签页：

| 标签页 | 内容 |
|---|---|
| 🔍 查询结果 | 本次查询的明细，每行一个 JIG |
| 📊 结果透视 | 本次查询按 P/N 和工序汇总 |
| 📈 全量透视 | 全部数据汇总，可切「全部数据 / 生产中」 |
| 📋 数据审查 | 全部在产明细，可按 P/N 筛选，也可只显示尺寸不匹配的行 |

**尺寸验证（默认开启）**：「查询结果」页会自动把尺寸对不上的 JIG 标红——这些 JIG 的编号与型号应有的尺寸对不上，需要现场确认。标红行数显示在标签栏右侧，状态栏里也有；导出 Excel 时红色标记会一起保留。

**数据审查**：「数据审查」页列出全部在产（`JIG状态 = INPRODUCTION`）的 JIG，和查询结果不同，它不限于本次输入的那几个编号。工具条左侧的 P/N 下拉先按料号收窄，再用两个按钮切换视野：

| 按钮 | 显示内容 |
|---|---|
| 所有对象 | 该 P/N 下的全部记录 |
| 尺寸不匹配 | 只留标红的行 |

两个按钮后面都带行数。**导出的是当前视野的内容** —— 切到「尺寸不匹配」再点导出，拿到的就是一份纯异常清单，可以直接发给现场。

**工序轨道**（透视页顶部）：把产线的各道工序按顺序排开，每道工序显示当前有多少个 JIG 停在那里，置灰表示没有。产线卡在哪一步一目了然。轨道中间那道竖线是**「可用 / 非可用」的分界**——左侧五道（PNP ～ Jig Unloading）算可用工序，右侧为非可用。

### 导出

点顶栏的「导出」（在「加载」右侧，鼠标悬停会显示当前导的是哪张表），选择保存位置。文件名会自动带时间戳（可在设置里关闭），不会覆盖旧文件。
「数据审查」页导出的是当前视野（所有对象 / 尺寸不匹配）的内容。

### 维护型号与尺寸的对应关系

点顶栏「设置」，左侧选「型号尺寸匹配」，维护「Jig 对应型号 → 对应尺寸」的规则（例如 `184 → 65/55`，含义是该型号能做 65×55 的玻璃）。

- 尺寸写法用 `65/55`，多规格用下划线分隔，如 `65/55_77/48_83/48`
- 型号下写 `All Size` 表示该型号不限尺寸，永远不会标红
- 规则的顺序可以**拖动行首的手柄直接调**（拖动时其余行会实时让位），也可以点 ↑↓ 逐行微调
- 保存后已加载的表格会自动重算，不用重新加载源文件

### 设置

顶栏「设置」是一个左侧分类、右侧内容的窗口，四类：**文件 / 界面 / 数据处理 / 型号尺寸匹配**。底部「保存设置」一次性保存全部改动；若映射表里有重复或空型号，会拦住保存并自动跳到那一类。

### 外观

主题可切「浅色 / 深色 / 跟随系统」：在「设置 → 界面 → 主题」里选（即时预览，点「取消」还原），也可以直接点顶栏最右侧的图标一键切换浅 / 深。

## 三、常见问题

**Q：双击没反应 / 闪退**
系统缺 WebView2 运行时。到微软官网下载「Evergreen Standalone Installer」安装后重试：
https://developer.microsoft.com/microsoft-edge/webview2/

**Q：提示「源文件中未找到 Jig ID 列」**
源文件表头里没有 `Jig ID` 这一列。请确认选对了 MES 导出的文件。

**Q：粘贴后没反应**
「设置 → 数据处理 → 粘贴时提取 JIG ID」需处于开启状态。另外含空格或特殊字符的内容不会被识别为 JIG ID。

**Q：尺寸验证把整列都标红了**
`对应尺寸` 列依赖「Jig 对应型号」列的映射。型号不在映射表内时尺寸为空，空值默认视为匹配，不会标红。如果型号明明存在却没尺寸，请联系反馈。

**Q：窗口关掉了，人还在吗？**
默认「关闭时最小化到系统托盘」。双击托盘图标恢复，右键托盘图标 →「退出程序」才真正退出。可在设置里改。

**Q：配置存在哪？**
`%APPDATA%\JIG Data Finder\config.json`。升级新版时会沿用旧版（1.x）的配置，不用重新设置。

**Q：数据量大会不会卡？**
10 万行实测流畅（表格只渲染可视区的行）。加载 10 万行约 3 秒。

**Q：如何卸载**
删掉 `jig-data-finder.exe` 即可。配置在 `%APPDATA%`，如需彻底清除一并删除该目录。
